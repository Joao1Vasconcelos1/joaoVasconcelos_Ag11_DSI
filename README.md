# 📋 Análise da Situação do Reservatório de Água 🚰 - Exibição e alerta do nível de um resevartório de água. ❗

Este projeto em **Python** foi criado com o objetivo de exibir mensagens de alerta com cores diferentes, conforme o nível de água do reservatório para auxiliar um monitoramento simples.

O sistema trabalha com cinco níveis de água, representados em uma lista, indo de um nível mais baixo até o nível máximo do reservatório. 

Para cada nível ser associado a uma mensagem de alerta e a uma cor, seguindo a progressão de risco, está sendo utilizada a biblioteca **colorama**, permitindo destacar cada situação com uma cor específica.

# 📝 Instruções para executar o programa

Na simulação é informado apenas a **Quantidade de água em litros**.
